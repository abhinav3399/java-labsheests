# Java Lab Sheets

This folder contains the imported Java lab-sheet exercises organized by topic/worksheet.

## Folders
- `oops-01-main` — basic Java and class exercises
- `oops-02-main` — conditionals, loops, number and bitwise exercises
- `oops-03-main` — arrays and matrices
- `Oops-04-main` — classes, encapsulation, and inheritance exercises
- `oops-05-main` — companion/main classes for OOP exercises
- `oops-06-main` — abstraction and related OOP exercises

Only source files are included; compiled `.class` output and repository metadata are excluded.

## Run a program
Open a worksheet folder in VS Code and run a `.java` file with the Java extension, or compile it from a terminal:

```bash
javac Q1.java
java Q1
```

Use the matching public class name when compiling/running other exercises.
